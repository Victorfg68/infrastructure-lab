# Linux Fundamentals

Prácticas iniciales de administración Linux realizadas en un entorno de laboratorio con Rocky Linux 10.2 sobre VMware.

## Objetivo

Adquirir y practicar los fundamentos necesarios para administrar sistemas Linux, comprendiendo la gestión de usuarios, permisos, procesos y servicios del sistema.

## Contenido

| Práctica | Descripción |
|---|---|
| [01 - Users, Groups and Permissions](01-users-groups-and-permissions/) | Creación y gestión de usuarios, grupos y permisos básicos. |
| [02 - File Ownership and Special Permissions](02-file-ownership-and-special-permissions/) | Propietarios, grupos, umask, SUID, SGID y Sticky Bit. |
| [03 - Process Management](03-process-management/) | Identificación, supervisión y gestión de procesos. |
| [04 - Systemd Services](04-systemd-services/) | Gestión de servicios mediante systemd y systemctl. |

## Entorno de laboratorio

- Sistema operativo: Rocky Linux 10.2.
- Plataforma de virtualización: VMware.
- Usuario administrador: Admin.
- Usuario de pruebas: dev1.
- Grupo de trabajo: developers.

## Aprendizajes

Esta fase proporciona los fundamentos necesarios para continuar con la administración de servicios Linux, servidores web y plataformas middleware.
