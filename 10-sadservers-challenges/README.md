# SadServers Challenges

Resolución y documentación de escenarios prácticos de administración de sistemas Linux mediante SadServers.

## Objetivo

Practicar troubleshooting, diagnóstico de incidencias y resolución de problemas en entornos Linux, documentando el procedimiento seguido, la causa raíz y las soluciones aplicadas.
